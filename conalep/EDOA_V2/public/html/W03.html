Documento interactivo con fichas inteligentes

Inicio · dictado
RA 1.3 · Integra herramientas digitales para organizar y presentar información.
Transformar un documento de texto en una evidencia interactiva usando fichas inteligentes.

Un documento digital profesional no solo contiene texto. También puede incluir elementos interactivos que ayudan a organizar información, dar seguimiento a tareas y comunicar el estado de un proceso.

En Google Docs, las fichas inteligentes permiten insertar fechas, archivos, personas, menús desplegables y otros elementos usando el símbolo arroba.

Desarrollo · actividad del alumno
  1. Crear un documento llamado Semana 03 - Gestión de documentos.
  2. Escribir título, subtítulo, nombre completo, grupo, módulo y fecha.
  3. Agregar un párrafo breve sobre la importancia de organizar documentos.
  4. Insertar un menú desplegable llamado Estado de revisión: Pendiente, En proceso y Terminado.
  5. Insertar una ficha de fecha para registrar la entrega.
  6. Agregar un enlace o ficha hacia Classroom, Drive o un archivo relacionado con la materia.
  7. Revisar que el documento tenga presentación limpia antes de continuar.
Reto: El menú debe funcionar y tener colores claros. No se acepta como texto escrito manualmente.
Producto parcial: Documento de Google Docs con fichas inteligentes funcionando.

Lista de verificación y código QR

Inicio · dictado
RA 1.3 · Usa recursos digitales para controlar requisitos y compartir información.
Crear una sección de control con casillas de verificación y un QR funcional.

Una lista de verificación permite controlar pasos, requisitos o pendientes dentro de un documento.

Cuando se combina con enlaces, códigos QR o recursos digitales, el documento se convierte en una guía de trabajo que puede consultarse y comprobarse fácilmente.

Desarrollo · actividad del alumno
  1. Agregar el apartado Lista de verificación de entrega.
  2. Insertar al menos 8 casillas de verificación con requisitos reales del documento.
  3. Cuidar que cada requisito sea breve, claro y verificable.
  4. Generar o insertar un código QR hacia un recurso útil de clase.
  5. Centrar el QR y escribir debajo una frase breve de uso.
  6. Probar el QR desde un celular o con apoyo del docente.
  7. Corregir enlace o permiso si el QR no abre.
Reto: El QR debe abrir un recurso real. Si el enlace pide acceso o falla, el producto no está completo.
Producto parcial: Lista de verificación con casillas y QR funcional.

Diagrama de proceso y firma digital

Inicio · dictado
RA 1.3 · Representa procesos mediante elementos visuales dentro del documento.
Insertar un diagrama y una firma digital para reforzar la presentación formal.

El lienzo de dibujo de Google Docs permite crear elementos visuales dentro del documento sin abrir otro programa.

Con esta herramienta se pueden hacer firmas, diagramas sencillos, flechas, cuadros de proceso y organizadores visuales que ayudan a explicar una idea.

Desarrollo · actividad del alumno

  4. Usar formas, flechas, color y texto legible.
  5. Insertar el dibujo dentro del documento.
  6. Crear una firma digital con línea a mano alzada o formato formal.
  7. Colocar la firma al final del documento con nombre y grupo.
Reto: El diagrama debe explicar el proceso. No debe ser una decoración sin sentido.

Inicio · dictado
RA 1.3 · Adapta plantillas digitales con información propia y formato profesional.
Usar una plantilla de Docs como base de un currículum o documento formal escolar.

Usar una plantilla no significa copiar sin pensar; significa aprovechar una estructura y adaptarla con información propia, ordenada y revisada.

  6. Agregar firma digital y un menú desplegable de nivel de dominio.

Reto: La plantilla debe adaptarse con información propia. No se acepta como formato vacío o texto sin revisar.

Primer contacto con Google Sheets

Inicio · dictado
RA 1.3 · Organiza información en filas, columnas y celdas.
Crear una hoja de cálculo con datos organizados y formato visual básico.

Una hoja de cálculo es una herramienta que organiza información en filas y columnas.

Las columnas se identifican con letras, las filas con números y la intersección entre una columna y una fila se llama celda. A diferencia de un documento de texto, una hoja de cálculo permite ordenar, comparar, calcular y presentar datos.

Desarrollo · actividad del alumno
  1. Crear una hoja llamada Semana 03 - Inventario personal.
  2. Elegir un tema: videojuegos, películas, canciones, libros, apps, gastos escolares o materiales.
  3. Crear 6 columnas: nombre, categoría, año o fecha, plataforma o tipo, calificación o cantidad y observación.
  4. Capturar mínimo 10 registros reales o coherentes.
  5. Aplicar color de relleno a encabezados.
  6. Usar negrita, bordes, ajuste de ancho y alineación.
  7. Congelar la fila 1 y verificar que ningún dato quede cortado.
Reto: La tabla debe poder leerse en pantalla sin que el docente pregunte qué significa cada columna.
Producto parcial: Hoja de cálculo con inventario personal y formato profesional.

Sesión 03 · Jueves · Hora 6

Operaciones básicas y autocompletar

Inicio · dictado
RA 1.3 · Aplica fórmulas básicas para calcular información.
Construir una tabla con fórmulas de subtotal, descuento y total.

En una hoja de cálculo, una fórmula siempre inicia con el signo igual.

Si no se escribe el signo igual, el programa interpreta la información como texto común. Las fórmulas permiten sumar, restar, multiplicar y dividir datos usando referencias de celda.

Desarrollo · actividad del alumno
  1. Crear una pestaña llamada Operaciones.
  2. Construir una tabla con 20 filas.
  3. Usar las columnas producto, cantidad, precio unitario, subtotal, descuento y total.
  4. Calcular subtotal multiplicando cantidad por precio unitario.
  5. Calcular descuento con el porcentaje indicado por el docente.
  6. Calcular total restando el descuento al subtotal.
  7. Usar autocompletar para copiar fórmulas y aplicar formato de moneda.
Reto: Si se cambia la cantidad o el precio, los resultados deben actualizarse automáticamente.
Producto parcial: Pestaña de operaciones con 20 filas calculadas.

Sesión 03 · Jueves · Hora 7

Referencia absoluta y creador de tablas

Inicio · dictado
RA 1.3 · Usa referencias absolutas para mantener datos fijos en fórmulas.
Diseñar una herramienta que cambie resultados al modificar una celda principal.

Una referencia absoluta sirve para fijar una celda dentro de una fórmula. Se representa con el símbolo de dólar, por ejemplo $A$1.

Cuando una celda se fija, la fórmula puede copiarse hacia abajo o hacia los lados sin perder el dato principal.

Desarrollo · actividad del alumno
  1. Crear una pestaña llamada Creador de tablas.
  2. Elegir una celda principal para escribir el número base.
  3. Crear una columna con números del 1 al 20.
  4. Crear la fórmula que multiplique cada número por la celda principal.
  5. Usar referencia absoluta para fijar la celda principal.
  6. Cambiar el número base y comprobar que toda la tabla se actualiza.
  7. Agregar instrucciones breves, color para entrada de datos y color para resultados.
Reto: La hoja debe funcionar como herramienta: al cambiar un solo dato, cambia toda la tabla.
Producto parcial: Creador de tablas con referencia absoluta funcionando.
