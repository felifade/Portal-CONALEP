Configuración de la Pestaña 2 y bitácora

Inicio · dictado

Esta semana Google Docs funcionará como bitácora de trabajo y Google Sheets como herramienta técnica para organizar información.

La bitácora permite documentar el proceso, guardar evidencias y explicar con claridad qué se hizo, cómo se hizo y qué producto se obtuvo.

Una hoja de cálculo es una herramienta digital organizada en filas y columnas. Su propósito es almacenar, estructurar, calcular y analizar datos mediante fórmulas y funciones automáticas.

Docs documenta
  1. Abrir desde Classroom el documento maestro del RA 1.3.
  2. Crear la Pestaña 2 y nombrarla Semana 04.
  3. Diseñar portada formal: módulo, alumno, grupo, docente y fecha.
  4. Insertar checklist con casillas interactivas.
  5. Escribir propósito, dictado y definición técnica.
  6. Justificar texto y resaltar conceptos clave en negrita.
Sheets practica
  1. Preparar el espacio donde se pegará el vínculo del directorio.
  2. Identificar que Sheets será la práctica técnica de la semana.
  3. Dejar lista la bitácora para recibir evidencias por hora.
Producto: Pestaña 2 estructurada con portada formal, checklist activo, propósito, dictado justificado y definición técnica.

Formato profesional y congelado de paneles

Inicio · dictado

El diseño en una hoja de cálculo tiene una función operativa: jerarquizar los encabezados, evitar que se pierdan de vista y asegurar la legibilidad del dato registrado.

El formato no es decoración; permite revisar información de forma más rápida, clara y profesional.

Docs documenta
  1. Tomar captura de la tabla con formato profesional.
  2. Pegarla en la Pestaña 2.
  3. Explicar qué cambios visuales mejoraron la lectura.
  4. Verificar que la imagen quede centrada y sin deformarse.
Sheets practica
  1. Congelar la Fila 1 para mantener visibles los encabezados.
  2. Aplicar color de fondo oscuro y texto claro en negrita.
  3. Ajustar el ancho óptimo de cada columna.
  4. Centrar datos cortos: No. Lista, Edad, Sexo y PC Lab.
  5. Alinear a la izquierda nombres, colonias y correos.
  6. Aplicar bordes delgados a toda la matriz.
Producto: Directorio con encabezados inmovilizados, formato profesional, columnas legibles, bordes y evidencia visual en Docs.

Validación de datos con listas desplegables

Inicio · dictado

La validación de datos restringe la entrada de información en una celda a valores predeterminados.

Esta función reduce errores tipográficos y permite que las fórmulas, filtros y consultas trabajen con información consistente.

Docs documenta
  1. Tomar captura de una lista desplegable activa.
  2. Pegar la evidencia en la Pestaña 2.
  3. Explicar por qué la validación reduce errores.
  4. Cerrar la evidencia de la sesión con una breve revisión.

  2. Crear chips de color para Dispositivo en Casa: Laptop, PC Escritorio, Solo Celular, Tablet, Ninguno.
  3. Validar que Cumpleaños use formato de fecha.
  4. Revisar que todos los registros cumplan la validación sin alertas.

Filtros y ordenamiento

Inicio · dictado

Filtrar no borra información: solo muestra los datos que cumplen una condición.

Ordenar permite acomodar registros por nombre, cantidad, precio o categoría para analizarlos más rápido.

Docs documenta

Sheets practica

  2. Ordenar por categoría.
  3. Ordenar por precio de mayor a menor.
  4. Filtrar estado Bajo o Agotado.

Fórmulas básicas

Inicio · dictado

En una hoja de cálculo, una fórmula siempre inicia con el signo igual.

Las fórmulas permiten obtener resultados usando referencias de celda, no escribiendo el resultado manualmente.

Docs documenta

  2. Insertar captura de resultados.
  3. Explicar qué cambió al modificar cantidad o precio.
  4. Registrar evidencia de autocompletar.
Sheets practica

  2. Calcular subtotal con cantidad por precio.
  3. Calcular descuento con porcentaje indicado.
  4. Usar autocompletar para copiar fórmulas.
