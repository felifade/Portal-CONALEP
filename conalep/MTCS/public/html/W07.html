Jueves · Sesión 02 · Hora 2

Hora 2: ¿Quién manda aquí? Root vs Sudo

👑 El Superusuario Supremo

🎙️ Texto para Dictar
"En Linux, 'root' es el Dios del sistema con UID 0. Puede borrar el disco duro completo sin pedir confirmación. Por seguridad, nunca se trabaja como root; usamos 'sudo' para pedir permiso temporal."

En Windows sale una ventana que te dice "¿Desea permitir que esta aplicación haga cambios?". En Linux la terminal confía ciegamente en quien tenga permisos root.

💻 Práctica en Terminal (Google Cloud Shell)

# 1. Comprueba tu nombre de usuario
whoami

# 2. Revisa tu credencial numérica (UID y GID)
id

# 3. Inspecciona el registro oficial de cuentas
head -n 5 /etc/passwd
Acordeón para ti: Explícales que UID 0 es root, y los usuarios normales empiezan a partir de UID 1000. En /etc/passwd cada línea tiene 7 campos separados por dos puntos (:).

Jueves · Sesión 02 · Hora 3

Hora 3: Anatomía de los Permisos (r, w, x)

🔤 Las Tres Letras y los Tres Grupos

  • r (Read / Lectura): Abre y lee el contenido.
  • w (Write / Escritura): Modifica, sobrescribe o borra.
  • x (Execute / Ejecución): Corre el archivo como aplicación.
- r w x r - x r - -
| [---] [---] [---]
| | | +-- Otros (o): solo leen (r--)
| | +-------- Grupo (g): leen y ejecutan (r-x)
| +-------------- Dueño (u): control total (rwx)
+------------------ Tipo: '-' archivo normal / 'd' carpeta

✍️ Ejercicio Guiado en Libreta

💡 Clave de Respuestas para el Docente

1. -rwxr-xr-x: ¿Pueden otros borrarlo? ➔ NO (les falta la 'w').
2. -rw-------: ¿Quién puede leerlo? ➔ Solo el Dueño.
3. -rwxrwxrwx: ¿Qué riesgo tiene? ➔ Cualquiera puede modificarlo o destruirlo.

Viernes · Sesión 03 · Hora 4

Hora 4: La Matemática de Permisos (chmod Octal)

🔢 La Suma Secreta: 4 - 2 - 1

🎙️ Texto para Dictar
"Para cambiar permisos rápidamente, usamos números octales sumando valores:
r = 4 | w = 2 | x = 1 | - = 0
El comando para aplicar permisos se llama 'chmod' (Change Mode)."
r w x = 4 + 2 + 1 = 7 (Todo)
r w - = 4 + 2 + 0 = 6 (Lectura y Escritura)
r - x = 4 + 0 + 1 = 5 (Lectura y Ejecución)
r - - = 4 + 0 + 0 = 4 (Solo Lectura)

🏢 Los Códigos de la Industria Real

  • chmod 777: El pecado mortal. Jamás usarlo en servidores reales.
  • chmod 755: Estándar para carpetas y páginas web públicas.
  • chmod 644: Estándar para archivos de texto y documentos.
  • chmod 600 / 700: Modo blindado (solo el dueño puede acceder).
Pregunta al Grupo: ¿Qué número es -rwxr-xr--?
Respuesta: Dueño (7) Grupo (5) Otros (4) ➔ 754.

Viernes · Sesión 03 · Hora 5

Hora 5: Laboratorio "Blindando el Servidor"

🚨 El Servidor Vulnerable (Simulación)

Un administrador novato dejó archivos confidenciales expuestos al público con 777:

mkdir -p lab_semana07 && cd lab_semana07
touch clave_servidor.key base_datos.sql web.html
chmod 777 *
ls -l
💡 Para el Docente

Los alumnos verán los archivos en verde brillante (alerta de peligro). Su misión es blindarlos uno por uno.

🛡️ Misión de Respuesta (Blue Team)

Comandos exactos que los alumnos deben ejecutar para blindar el servidor:

# 1. Clave secreta (SOLO el dueño puede leerla)
chmod 600 clave_servidor.key

# 2. Base de datos (Dueño escribe, grupo lee)
chmod 640 base_datos.sql

# 3. Web pública (Todos leen, solo dueño escribe)
chmod 644 web.html

# 4. Validar el blindaje
ls -l
