Sesión 01 · Taller Práctico (Bloque 2 Horas)

Misión Cloud Recon: Pasos de Auditoría en la Nube

Acceder a shell.cloud.google.com en el navegador. Sigue el orden estricto de las 4 fases y anota cada hallazgo en tu libreta:

Fase 1

1. Identidad

  • Ejecuta whoami para verificar tu cuenta de usuario.
  • Ejecuta id para registrar tu UID numérico y grupos.
  • Ejecuta uptime para ver el tiempo encendido y carga media.
Fase 2

2. Hardware Real

  • Ejecuta lscpu e identifica el procesador Intel Xeon o AMD EPYC.
  • Ejecuta free -h y anota la memoria RAM total y libre.
  • Ejecuta df -h y confirma los 5 GB persistentes en /home.
Fase 3

3. Archivos /etc

  • Ejecuta cat /etc/os-release para ver la versión de Debian.
  • Ejecuta cat /etc/passwd | head -n 10 y observa las cuentas de servicio.
  • Ejecuta cat /etc/resolv.conf para auditar el DNS interno.
Fase 4

4. Red y Mapa

  • Ejecuta hostname -I para ver la IP privada en la nube.
  • Ejecuta curl -s ifconfig.me para obtener la IP pública de Google.
  • Abre iplocation.io en el navegador, pega la IP y ubica el Data Center.
  • Ejecuta ping -c 4 8.8.8.8 y mide la latencia (< 1 ms).

Sesión 02 · Taller Práctico (Bloque 2 Horas)

Edición en Terminal y Creación de Bitácora

Manipulación de archivos en consola remota y consolidación del reporte en Google Docs.

Paso 1: Estructura

Crear y Navegar

  • Crear carpeta de práctica:
    mkdir lab_mtcs
  • Ingresar a la carpeta:
    cd lab_mtcs
  • Comprobar ruta actual:
    pwd
  • Confirmar que estás dentro de tu carpeta antes de crear archivos.
Paso 2: Edición

Editor Nano

  • Abrir editor:
    nano bitacora_semana06.txt
  • Escribir tus datos (Nombre, Grupo 501, Módulo MTCS-20).
  • Guardar cambios:
    Ctrl + O y presionar Enter.
  • Salir de nano:
    Ctrl + X.
  • Leer contenido:
    cat bitacora_semana06.txt
  • Buscar línea:
    grep "ALUMNO" bitacora_semana06.txt
Paso 3: Reporte

Evidencia Digital

  • Limpiar consola con clear.
  • Ejecutar whoami y cat bitacora_semana06.txt.
  • Capturar pantalla completa de la terminal con ambos comandos visibles.
  • Pegar la captura en tu documento formal de Google Docs y solicitar firma docente.

Batería Completa de Comandos · Semana 06

Reconocimiento de Sistema y Red

  • whoami ➔ Identidad del usuario activo en Linux.
  • id ➔ UID, GID y grupos de seguridad asignados.
  • uptime ➔ Tiempo encendido y carga promedio del procesador.
  • lscpu ➔ Arquitectura y modelo de procesador del servidor.
  • free -h ➔ Memoria RAM total, utilizada y disponible.
  • df -h ➔ Particiones y espacio disponible en disco duro.
  • hostname -I ➔ Dirección IP privada interna en la nube.
  • curl -s ifconfig.me ➔ Dirección IP pública de salida a internet.

Archivos, Directorios y Edición

  • pwd ➔ Imprime la ruta absoluta del directorio actual.
  • ls -la ➔ Lista todos los archivos, permisos y archivos ocultos.
  • cd / ➔ Cambia al directorio raíz de todo el sistema.
  • cd ~ ➔ Regresa de inmediato a tu carpeta de usuario personal.
  • mkdir [carpeta] ➔ Crea un nuevo directorio de trabajo.
  • nano [archivo] ➔ Editor de texto plano en consola (Ctrl+O / Ctrl+X).
  • cat [archivo] ➔ Imprime el contenido completo de un archivo en pantalla.
  • clear ➔ Limpia la pantalla de la terminal.
